# Changelog

## [0.2 (9-14-2026)]

### Added
- Menu option to change size of on-screen touch controls
- More controller mapping options
- Cheats menu, available from in-game pause menu

### Changed
- Placement of some menu items

### Fixed
- Triggers now map-able

## [0.1 (8-31-2026)]

### Added
Mostly Vanilla Descent.
 - Gamepad support
 - Render scaling+
 - FPS counter
 - Content file selector
 - Gamepad rebinding
 - Various menu navigation
 - Force 4:3 mode, use to force a 4:3 scale adding black bars. 
 - If you are using a 4:3 device already like a Nova you don't need to enable this.

### Changed
 - Touch controls auto-show/hide based on gamepad availability

### Fixed
 - Misc. renderer and content pipeline fixes
 - Various quality of life and bug fixes
